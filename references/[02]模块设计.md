
# 功能模块设计

## 2.1 模块总览

| 模块 | 职责 | 输入 | 输出 |
|---|---|---|---|
| 数据接入 | 文件/CDC/Kafka 接入 | 源系统数据 | ODS/Bronze |
| ODS 原始镜像 | 1:1 保留源数据 | 接入数据 | ods_* |
| OWD 标准化 | 清洗、编码、汇率、引用关联 | ODS | owd_* |
| OWS 汇总 | 分桶、聚合、现金流 | OWD | ows_* |
| ADS 报表 | FR 2052a 对齐、报送 | OWS | ads_* |
| 引用数据 | 实体、币种、期限、HQLA、评级 | 主数据 | ref_* |
| 数据质量 | 规则校验、GE、dbt tests | 各层数据 | 校验日志 |
| GL 对账 | 总账与 FR 2052a 对账 | GL + OWS | 对账结果 |
| 重述 | 迟到数据、修正、SCD2 | 修正数据 | 新版本 + 审计 |
| 监管映射 | 字段与 FR 2052a 规则绑定 | dbt meta | DataHub 业务血缘 |
| PII 脱敏 | 动态脱敏、权限控制 | OWD/ADS | 脱敏视图 |
| 调度编排 | Airflow DAG | 时间/事件 | 任务运行 |
| 监控告警 | SLA、失败、异常波动 | 日志/指标 | 告警 |
| 元数据治理 | DataHub 摄取 | dbt/DB | 血缘目录 |

## 2.2 数据接入模块

- 批文件：CSV/JSON/XML 到达指定目录。
- CDC：核心银行、贷款系统变更捕获。
- Kafka Topics：
  - `core_banking_txns`
  - `treasury_deals`
  - `derivatives_trades`
  - `market_data_prices`
  - `gl_entries`
  - `reference_data_updates`
  - `fr2052a_alerts`
- 接入校验：文件完整性、行数偏差、关键字段非空、T+1 08:00 前到达。

## 2.3 ODS 模块

- 1:1 映射源系统。
- 保留原始字段、原始值。
- 增加 ETL 元数据：`etl_load_timestamp`、`etl_batch_id`、`etl_source_file`。
- 主要表：
  - `ods_deposits`
  - `ods_repo_transactions`
  - `ods_loans`
  - `ods_securities`
  - `ods_derivatives`
  - `ods_counterparty_ref`
  - `ods_gl_balances`
  - `ods_off_bs_commitments`

## 2.4 OWD 模块

- 数据清洗、去重、标准化。
- 统一编码：ISO 4217、ISO 3166、LEI、NAICS。
- 统一币种：按报告日即期汇率转 USD。
- 关联引用数据，丰富维度。
- 基础校验：金额、利率、币种、日期、评级。
- 主要表：
  - `owd_deposits`
  - `owd_secured_financing`
  - `owd_loans`
  - `owd_securities`
  - `owd_derivatives`
  - `owd_off_bs`
  - `owd_gl_mapping`

## 2.5 OWS 模块

- 按报表维度聚合。
- 到期期限分桶：O/N、1-7D、8-30D、31-90D、91-180D、181D-1Y、>1Y、OPEN。
- 现金流计算：流入、流出、净额。
- HQLA 分类：Level 1 / 2A / 2B / Non-HQLA。
- 业务校验与交叉校验。
- 主要表：
  - `ows_funding_summary`
  - `ows_collateral_summary`
  - `ows_cash_position`
  - `ows_cashflow_projection`
  - `ows_hqla_summary`

## 2.6 ADS 模块

- 完全对齐 FR 2052a 报表结构。
- 生成 Section A-K 汇总与明细。
- 最终校验与审计追踪。
- 生成 XBRL/XML/CSV。
- 主要表：
  - `ads_fr2052a_report`
  - `ads_fr2052a_detail`
  - `ads_fr2052a_validation_log`
  - `ads_fr2052a_submission`
  - `ads_gl_reconciliation`
  - `ads_restatement_log`

## 2.7 数据质量模块

| 规则 | 层级 | 内容 | 严重度 |
|---|---|---|---|
| VDQ-001 | ODS | 文件完整到达 | ERROR |
| VDQ-002 | ODS | 关键字段非空 | ERROR |
| VDQ-003 | OWD | 金额 >= 0 | ERROR |
| VDQ-004 | OWD | 利率合理 | WARNING |
| VDQ-005 | OWD | 币种 ISO 4217 | ERROR |
| VDQ-006 | OWD | outstanding <= facility | ERROR |
| VDQ-007 | OWD | Repo 抵押品市值合理 | WARNING |
| VDQ-008 | OWD | 到期日 >= 报告日 | ERROR |
| VDQ-009 | OWD | 汇率转换误差 < 1% | WARNING |
| VDQ-010 | OWS | 汇总 = SUM 明细 | ERROR |
| VDQ-011 | OWS | 非受限资产 <= 总资产 | ERROR |
| VDQ-012 | OWS | 已质押 <= 总市值 | ERROR |
| VDQ-013 | ADS | Section 合计 = 行项目合计 | ERROR |
| VDQ-014 | ADS | 总融资与资产负债表偏差 < 5% | WARNING |
| VDQ-015 | ADS | 环比波动 < 20% | WARNING |
| VDQ-016 | ODS | T+1 08:00 ET 前加载 | ERROR |
| VDQ-017 | ADS | L2A+2B <= 总 HQLA 40% | WARNING |
| VDQ-018 | ADS | 现金流入 cap = 总流出 75% | ERROR |
| VDQ-019 | ADS | 必填行项目非空 | ERROR |
| VDQ-020 | OWD | LEI 格式校验 | WARNING |

## 2.8 GL 对账模块

- 从财务总账获取科目余额。
- 与 OWS/ADS 汇总对账。
- 差异超过阈值则阻断报送。
- 输出：`ads_gl_reconciliation`。
- 关键字段：`report_date`、`gl_account_id`、`gl_amount`、`fr2052a_amount`、`variance`、`status`。

## 2.9 重述模块

- 迟到数据、错误修正、监管重述。
- SCD2 记录版本：`valid_from`、`valid_to`、`is_current`、`change_reason`。
- Iceberg Time Travel 还原历史快照。
- Airflow `backfill_and_restate` DAG。
- 输出：`ads_restatement_log`。

## 2.10 监管映射与业务血缘

- dbt `schema.yml` 中配置 `meta`：
  - `regulatory_reference`
  - `rule_id`
  - `haircut_rate`
  - `owner`
- DataHub 摄取后展示：
  - 技术血缘：表 → 表 → 字段。
  - 业务血缘：字段 → FR 2052a 规则 → 页码 → Haircut。

## 2.11 PII 脱敏与权限

- dbt macro 动态脱敏。
- 角色：
  - `fr2052a_admin`
  - `compliance_officer`
  - `treasury_analyst`
  - `auditor`
- 规则：
  - 合规官可见明文。
  - 普通分析师仅见后 4 位。
  - 所有访问写审计日志。

## 2.12 调度与监控

- Airflow DAG：
  - `fr2052a_daily_batch`
  - `fr2052a_realtime_alert`
  - `fr2052a_backfill_and_restate`
  - `fr2052a_gl_reconciliation`
  - `fr2052a_submission`
- 监控：
  - Airflow SLA Miss。
  - GE 校验失败。
  - Kafka Lag。
  - Spark 作业失败。
  - PG 连接数、慢查询。
  - MinIO 容量。
  - DataHub 摄取状态。
