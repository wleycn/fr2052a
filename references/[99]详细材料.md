## 2.1 领域模型与实体关系

核心实体：

|---|---|---|
| 法人实体 | 合并口径、重要子公司 |
| 交易对手 | 央行、主权、银行、券商、企业、零售 |
| 金融产品 | 存款、融资、回购、贷款、证券、衍生品、表外 |

核心关系：
```text

交易对手 1--N 金融产品

报表 1--N 重述日志
```

## 2.2 分层处理规则

### ODS 层
- 1:1 映射源系统。
- 不修改业务值。
- 只增加 ETL 元数据。
- 必须保留 `source_system + source_record_id`。

### OWD 层
- 清洗、去重、标准化。
- 统一币种、国家、产品、评级、行业。
- 汇率转换：`amount_usd = amount_lc * fx_rate`。
- 到期分桶：按 `report_date` 到 `maturity_date` 的剩余天数。
- 映射 FR 2052a Section / Line Item。
- 生成 SCD2 版本字段。

### OWS 层
- 按 `report_date + entity_code + section + line_item + product + counterparty + currency + maturity_bucket + purpose` 聚合。
- 计算总余额、加权平均利率、加权平均到期天数、预期流入/流出、净现金流、HQLA 折扣后价值。
- 汇总金额 = SUM 明细金额，误差 < 0.01。

### ADS 层
- 完全对齐 FR 2052a。
- 生成 Section A-K。
- 生成明细行、执行最终校验、生成报送文件、记录报送状态与回执。

## 2.3 关键映射规则

### 到期分桶

| Bucket | 最小天数 | 最大天数 |
|---|---|---|
| O/N | 0 | 0 |
| 1-7D | 1 | 7 |
| 8-30D | 8 | 30 |
| 31-90D | 31 | 90 |
| 91-180D | 91 | 180 |
| 181D-1Y | 181 | 365 |
| >1Y | 366 | 99999 |
| OPEN | NULL | NULL |

### HQLA 规则

| 等级 | 示例 | Haircut |
|---|---|---|
| Level 1 | 现金、央行准备金、国债 | 0% |
| Level 2A | 机构债、GSE | 15% |
| Level 2B | 投资级公司债、部分股票 | 50% |
| Non-HQLA | 其他 | 不纳入 |

### 现金流 Cap 规则
- 预期现金流入 <= 总现金流出的 75%。
- 若超过，按 75% 截断，并记录校验警告。

### Operational 存款
- 清算、托管、现金管理相关存款标记为 `OPERATIONAL`。
- 流出率低于 `NON_OPERATIONAL`。

## 2.5 数据质量与 GL 对账

### GL 对账核心逻辑

```sql
SELECT
  l.report_date,                         -- 报告日期
  g.credit_balance AS gl_amount,         -- 总账贷方余额
  l.total_liability AS fr2052a_amount,   -- FR 2052a 汇总负债金额
  (g.credit_balance - l.total_liability) AS variance, -- 差异额
  CASE
    WHEN ABS(g.credit_balance - l.total_liability) < 0.01 THEN 'PASS'
    ELSE 'FAIL'
  END AS status                          -- 对账状态
FROM liquidity_totals l
JOIN gl_totals g
  ON l.report_date = g.report_date;
```

### 阻断规则
- 若 `status = FAIL`，Airflow 任务失败。
- 不允许生成报送文件。
- 触发邮件/企业微信告警。

重述流程：

```text
发现错误
  → 将旧版本 valid_to_date = 修正日 - 1，is_current_flag = false
  → 插入新版本 valid_from_date = 修正日，is_current_flag = true
  → 写入 fr2052a_db.ads.ads_restatement_log
  → 触发受影响日期重跑
  → Iceberg 保留 snapshot，供审计 Time Travel
```
