# 数据流与数据结构设计

## 3.1 端到端数据流

```text
源系统
  → Kafka / 批文件 / CDC
  → Iceberg Bronze / ODS
  → dbt + Spark / OWD
  → dbt + Spark / OWS
  → Iceberg Gold / ADS
  → PostgreSQL ADS
  → Great Expectations 校验
  → GL 对账
  → XBRL/XML/CSV 报送
  → DataHub 血缘与监管映射
```

## 3.6 SCD2 与重述设计

```sql
SELECT
    facility_id,
    outstanding_amount,
    valid_from_date,
    valid_to_date,
    is_current_flag,
    last_modified_reason
FROM owd_loans;
```

- `valid_to_date = '9999-12-31'` 表示当前有效。
- `last_modified_reason`：`ORIGINAL`、`LATE_ARRIVAL`、`CORRECTION`、`RESTATEMENT`。
- Iceberg 支持 `DELETE` + `INSERT` 或 `MERGE`，保留 snapshot。

## 3.7 关键业务规则

| 规则 | 说明 |
|---|---|
| 到期分桶 | 按剩余到期日，活期归 O/N |
| 合并 vs 子公司 | 合并抵消内部交易，子公司保留 |
| HQLA | L1 0% haircut；L2A 15%；L2B 50% |
| Operational 存款 | 清算/托管/现金管理，流出率低 |
| 现金流 Cap | 流入 <= 总流出 75% |
| 币种 | 报告日即期汇率转 USD |
| 净额结算 | 仅有有效净额协议时允许 |
| 监管重述 | 不直接 UPDATE，插入新版本并触发重跑 |
