# 🏦 FR 2052a 监管报表 — 数据处理演示项目

## 一、项目概览

### 1.1 FR 2052a 报表简介

FR 2052a 是美联储（Federal Reserve）的 **复杂机构流动性监控报告**，用于监控受美联储监管的大型复杂银行组织的整体流动性状况。报告按合并口径和重要实体子公司分别报送，涵盖广泛的融资分类（按产品、余额、用途和到期日分段）。

### 1.2 报表主要章节（Sections）

| Section | 名称 | 说明 |
|---------|------|------|
| **A** | Wholesale Unsecured Financing | 批发无担保融资（商业票据、大额存单、无担保借款等） |
| **B** | Wholesale Secured Financing | 批发有担保融资（回购协议、证券借贷等） |
| **C** | Deposits | 存款（零售/批发活期、储蓄、定期存款） |
| **D** | Other Funding / Liabilities | 其他资金来源/负债 |
| **E** | Cash & Cash Equivalents | 现金及现金等价物 |
| **F** | Loan Portfolio (Cash Inflows) | 贷款组合（现金流入） |
| **G** | Securities Portfolio | 证券投资组合 |
| **H** | Derivatives | 衍生品头寸及现金流 |
| **I** | Collateral Positions | 抵押品头寸 |
| **J** | Contingent Liabilities / Off-BS | 或有负债/表外项目 |
| **K** | Summary / Calculated Metrics | 汇总指标（LCR 补充、净资金流出等） |

## 二、从 FR 2052a 倒推所需数据

### 2.1 金融产品数据（Transaction/Product Data）

| 产品类别 | 具体产品 | 对应 Section |
|----------|---------|-------------|
| **存款** | 活期存款、储蓄存款、定期存款、大额存单(CD)、经纪存款 | C, A |
| **无担保融资** | 商业票据(CP)、中期票据(MTN)、联邦基金拆借、无担保借款 | A |
| **有担保融资** | 回购协议(Repo)、逆回购、证券借贷、FHLB 借款 | B |
| **贷款** | 商业贷款、零售贷款、按揭贷款、信用额度、银团贷款 | F |
| **证券** | 国债、机构债、MBS/ABS、公司债、股权证券 | G |
| **衍生品** | 利率互换、外汇远期、期权、期货、信用衍生品 | H |
| **表外项目** | 信用证、担保、贷款承诺、未使用额度 | J |

### 2.2 引用数据（Reference Data）

| 引用数据 | 用途 |
|----------|------|
| **实体/法人结构** | 合并 vs 子公司层级映射 |
| **币种代码** (ISO 4217) | 统一货币编码 |
| **国家/地区代码** (ISO 3166) | 交易对手所在地 |
| **交易对手信息** | 对手方类型（央行/主权/金融机构/企业/零售） |
| **产品类型编码** | FR 2052a 产品分类映射 |
| **到期期限分桶规则** | 报表要求的期限分段 (Overnight, 1-7d, 8-30d, 31-90d, 91-180d, 181d-1yr, >1yr) |
| **抵押品分类** | Level 1 HQLA, Level 2A, Level 2B, Non-HQLA |
| **信用评级映射** | 外部评级 → 内部评级标准化 |
| **行业分类** (SIC/NAICS) | 交易对手行业 |

### 2.3 辅助数据（Auxiliary/Surrounding Data）

| 辅助数据 | 用途 |
|----------|------|
| **汇率数据** | 外币头寸转换为报告币种 (USD) |
| **利率基准** | SOFR, Fed Funds Rate 等基准利率 |
| **日历数据** | 工作日/节假日、到期日调整 |
| **行为假设参数** | 存款流失率、贷款提取率、roll-off rate |
| **历史报送数据** | 日环比/月环比变动分析 |
| **监管规则参数** | 折算系数、流入流出上限系数 |

### 3.2 OWD 层 — 标准化明细

    exchange_rate        DECIMAL(18,8),
    -- 标准化利率
    interest_rate        DECIMAL(10,6),
    rate_type            VARCHAR(10),              -- FIXED / FLOATING

    -- 日期标准化
    open_date            DATE,
    maturity_date        DATE,
    days_to_maturity     INT,
    maturity_bucket      VARCHAR(20),              -- O/N, 1-7D, 8-30D, 31-90D, 91-180D, 181D-1Y, >1Y, OPEN
    -- 存款保险
    is_insured           BOOLEAN,

    -- FR 2052a 映射

    fr2052a_line_item    VARCHAR(20),              -- 报表行项目编码
    fr2052a_purpose      VARCHAR(30),              -- OPERATIONAL / NON_OPERATIONAL
    -- 数据质量标记
    dq_completeness_flag BOOLEAN       DEFAULT TRUE,
    dq_validity_flag     BOOLEAN       DEFAULT TRUE,
    dq_record_status     VARCHAR(10)   DEFAULT 'ACTIVE',  -- ACTIVE / REJECTED / SUSPECT

    record_update_time   TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    source_system        VARCHAR(20),
    source_record_id     VARCHAR(50),
    PRIMARY KEY (deposit_key),
    -- 金融数据检验约束
    CONSTRAINT chk_dep_currency CHECK (currency_code IN ('USD','EUR','GBP','JPY','CHF','CNY','HKD','AUD','CAD','SGD')),
    CONSTRAINT chk_dep_amount_pos CHECK (principal_amount_usd >= 0),
    CONSTRAINT chk_dep_rate CHECK (interest_rate BETWEEN -0.10 AND 1.0),
    CONSTRAINT chk_dep_segment CHECK (customer_segment IN ('RETAIL','SME','CORPORATE','FINANCIAL','SOVEREIGN')),
    CONSTRAINT chk_dep_product CHECK (product_category IN ('DEMAND','SAVINGS','TIME','CD','BROKERED','SWEEP','MMDA')),
    CONSTRAINT chk_dep_section CHECK (fr2052a_section IN ('A','C','D')),
    CONSTRAINT chk_dep_maturity_bucket CHECK (maturity_bucket IN ('O/N','1-7D','8-30D','31-90D','91-180D','181D-1Y','>1Y','OPEN'))

### 4.2 核心校验规则清单

| # | 规则ID | 类别 | 层级 | 校验内容 | 严重度 |
|---|--------|------|------|---------|--------|
| 1 | `VDQ-001` | 完整性 | ODS | 源系统数据文件必须完整到达，行数与预期偏差<0.1% | ERROR |
| 2 | `VDQ-002` | 完整性 | ODS | 关键字段 (amount, date, currency) 不允许为 NULL | ERROR |
| 3 | `VDQ-003` | 准确性 | OWD | 金额必须 >= 0（存款、贷款余额） | ERROR |
| 4 | `VDQ-004` | 准确性 | OWD | 利率必须在合理范围 (-10% ~ 100%) | WARNING |
| 5 | `VDQ-005` | 准确性 | OWD | 币种代码必须为有效 ISO 4217 代码 | ERROR |
| 6 | `VDQ-006` | 一致性 | OWD | 贷款 outstanding <= facility_amount | ERROR |
| 7 | `VDQ-007` | 一致性 | OWD | Repo collateral_mv >= cash_amount * (1 - max_haircut) | WARNING |
| 8 | `VDQ-008` | 一致性 | OWD | 到期日期 >= 报告日期（非到期资产） | ERROR |
| 9 | `VDQ-009` | 准确性 | OWD | 汇率转换验证：amount_usd ≈ amount_lc × fx_rate ± 1% | WARNING |
| 10 | `VDQ-010` | 一致性 | OWS | 汇总金额 = SUM(明细金额)，偏差 < $0.01 | ERROR |

### 4.3 校验执行 SQL 示例

```sql
-- 校验规则 VDQ-006: 贷款余额 ≤ 授信额度
INSERT INTO ads_fr2052a_validation_log 
    (report_id, validation_rule_id, rule_category, severity, check_result, 
     actual_value, expected_value, affected_section)
SELECT 
    :report_id,
    'VDQ-006',
    'CONSISTENCY',
    'ERROR',
    CASE WHEN COUNT(*) > 0 THEN 'FAIL' ELSE 'PASS' END,
    CONCAT(COUNT(*), ' violations found'),
    'outstanding_usd <= facility_amount_usd',
    'F'
FROM owd_loans
WHERE outstanding_usd > facility_amount_usd
  AND entity_code = :entity_code;

-- 校验规则 VDQ-014: 总融资 ≈ 资产负债表总负债
INSERT INTO ads_fr2052a_validation_log
    (report_id, validation_rule_id, rule_category, severity, check_result,
     actual_value, expected_value, variance, affected_section)
SELECT 
    r.report_id,
    'VDQ-014',
    'BUSINESS',
    'WARNING',
    CASE WHEN ABS(r.sec_a_total + r.sec_b_total + r.sec_c_total + r.sec_d_total - bs.total_liabilities) 
              / NULLIF(bs.total_liabilities, 0) > 0.05 
         THEN 'WARN' ELSE 'PASS' END,
    CAST(r.sec_a_total + r.sec_b_total + r.sec_c_total + r.sec_d_total AS VARCHAR),
    CAST(bs.total_liabilities AS VARCHAR),
    (r.sec_a_total + r.sec_b_total + r.sec_c_total + r.sec_d_total - bs.total_liabilities) 
        / NULLIF(bs.total_liabilities, 0),
    'A/B/C/D'
FROM ads_fr2052a_report r
JOIN balance_sheet_extract bs ON r.entity_code = bs.entity_code AND r.report_date = bs.report_date
WHERE r.report_id = :report_id;
```

### 5.3 关键业务规则说明

| 业务规则 | 说明 |
|---------|------|
| **到期期限分桶** | 按剩余到期日（非原始期限）计算，活期存款归入 O/N 桶 |
| **合并 vs 子公司** | 合并口径消除内部交易，子公司报送含内部交易 |
| **HQLA 分类** | Level 1 (国债/央行存款) → 0% haircut; Level 2A (机构债) → 15% haircut; Level 2B (投资级公司债) → 50% haircut |
| **Operational 存款** | 与运营活动相关的存款（清算/托管/现金管理），流出率更低 |
| **现金流 Cap** | 预期现金流入不超过总流出的 75%（保守原则） |
| **币种处理** | 所有外币头寸按报告日即期汇率转换为 USD |
| **净额结算** | 仅在有有效净额结算协议时允许净额处理 |

## 总结

本项目的核心设计思路：

1. **自顶向下分解**：从 FR 2052a 报表 11 个 Section 倒推所需的 6 大类产品数据 + 引用数据 + 辅助数据
2. **自底向上构建**：ODS（原始镜像）→ OWD（标准化明细）→ OWS（维度聚合）→ ADS（报表输出）
3. **全链路质量保障**：20+ 条校验规则贯穿各层，覆盖完整性、准确性、一致性、及时性、业务合理性
4. **审计可追溯**：每层保留 source_system + source_record_id，实现完整数据血缘
